# 🧸 PelukKata v4 — Perbaikan Login & Stabilitas Fitur

Versi `v4` memperbaiki kendala akses `localStorage` di beberapa lingkungan browser/preview (menggunakan *safe storage* dengan *fallback* memori), menjaga agar *error* ikon eksternal tidak menghentikan eksekusi JavaScript, serta menambahkan tombol **Isi Otomatis Akun Contoh (Naura)** di modal login.

## Cara Menjalankan
1. Ekstrak file ZIP ke satu folder.
2. Buka `index.html` di browser.
